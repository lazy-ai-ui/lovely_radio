# Lovely Radio

Бесконечное веб-радио без рекламы, пет-проект. Автор — product designer / design engineer.

**Главная платформа — iPhone Safari в обычной вкладке (не PWA).** Любое решение сначала проверяем на ней.

## Продукт

- Приложение состоит из нескольких «миров» (жанров). У каждого мира своя тема оформления и свой набор каналов.
- Первый мир — **нуар-джаз**: красный / чёрный / кремовый, ар-деко, жалюзи. Потом появятся другие жанры, а за ними нейрорадио (генеративные каналы).
- Станции — кураторский список на 10–15 штук, автор собирает его вручную. Динамических каталогов (Radio Browser и т.п.) нет.

## Стек

Ванильные HTML/CSS/JS, нативные ES-модули, **без сборщика и без npm-зависимостей**. Что лежит в репо, то и раздаёт Vercel.
Если захочется добавить Vite или фреймворк, сначала обсуди это с автором и объясни зачем.

## Структура

```
index.html            разметка каркаса, подключает токены, стили и src/main.js
channels.json         конфиг: миры → каналы
cover.png             обложка для Media Session (строго с нашего домена)
src/
  main.js             старт: грузит конфиг, связывает модули
  config.js           fetch + валидация channels.json
  player.js           <audio>, переключение каналов, зеркала, переподключение
  media-session.js    экран блокировки: метаданные, кнопки, playbackState
  ui.js               временный функциональный UI
  log.js              отладочный лог (виден с ?debug)
styles/app.css        стили компонентов — только семантические токены
tokens/base.css       общие токены: отступы, сетка, типошкала, радиусы, моушен
tokens/theme-*.css    тема мира: палитра → семантические токены, шрифты, текстуры
refs/                 визуальные референсы (в код не попадают)
spike/index.html      исходный техспайк — эталон iOS-поведения, не трогать
```

## channels.json

```jsonc
{
  "version": 1,
  "worlds": [{
    "id": "noir",             // стабильный id
    "name": "Нуар-джаз",
    "theme": "noir",          // → <html data-theme="noir"> и tokens/theme-noir.css
    "channels": [{
      "id": "secretagent",
      "type": "stream",       // "stream" | "generative"
      "enabled": true,        // необязательно; false — канал скрыт
      "name": "Secret Agent",
      "description": "…",
      "source": "SomaFM",     // в Media Session уходит как album
      "streams": ["https://…", "https://…"]  // зеркала по порядку, только https
    }]
  }]
}
```

- `type: "generative"` пока только заглушка в схеме (`generator: { engine, params }`). `config.js` такие каналы пропускает.
- Стримы, которые не начинаются с `https://`, отбрасываются при загрузке.
- Новую станцию сначала проверь на iPhone через превью-деплой и только потом мержи в main.

## Правила

### Дизайн-токены
- Слой **base** (`tokens/base.css`): сетка, отступы, типошкала, радиусы, моушен. Одинаков для всех миров.
- Слой **theme** (`tokens/theme-<мир>.css`, селектор `[data-theme="<мир>"]`): сырая палитра (`--noir-*`) плюс семантические токены.
- Компоненты (`styles/`) берут **только семантические токены**: `--surface`, `--surface-raised`, `--border`, `--text`, `--text-muted`, `--text-strong`, `--text-on-accent`, `--accent`, `--font-display`, `--font-text`, `--texture-*`, а также токены из base.
  **Никаких хардкод-цветов** и сырых палитровых переменных в компонентах.
- Новая тема обязана определить полный набор семантических токенов.
- `<meta name="theme-color">` не умеет читать CSS-переменные: держи его вручную в синхроне с `--surface`.

### iOS Safari: не ломать фон и Media Session
Эталон поведения — `spike/index.html`. После каждой правки плеера пройди этот чек-лист:

1. **Только https-стримы.** Страница открыта по https, http-стрим Safari заблокирует как mixed content.
2. **Первый звук только по тапу.** `audio.play()` вызывается синхронно из обработчика тапа или Media Session, **до любого `await`**. Всё асинхронное (конфиг и т.п.) грузится заранее, при старте страницы.
3. **Один `<audio preload="none" playsinline>` в DOM** на всё приложение. Не пересоздавать, не заменять на Web Audio без обсуждения: именно он играет в фоне при заблокированном экране.
4. **Media Session:** действия `play`, `pause`, `nexttrack`, `previoustrack`. `seekbackward`, `seekforward` и `seekto` выставлены в `null`, иначе iOS показывает ±10 сек вместо ⏮ ⏭. `playbackState` синхронизируется по событиям `playing`/`pause`.
5. **Обложка с нашего домена** (`cover.png`). Картинки с чужих доменов iOS на экране блокировки часто не показывает.
6. **После паузы переподключаемся** (заново ставим `src`), а не доигрываем старый буфер живого эфира.
7. **Ошибка стрима** → берём следующее зеркало из `streams`. Когда зеркала кончились, показываем статус «недоступен».

Что проверить руками на iPhone: запуск по тапу, звук при заблокированном экране, пришло уведомление — звук не сбился, на экране блокировки видны станция, обложка и ⏮ ⏭, переключение станций с экрана блокировки.

## Разработка и деплой

- Локально (fetch конфига не работает через `file://`):
  ```bash
  npx serve .
  ```
- Отладка на телефоне: открой страницу с `?debug`, внизу появится лог.
- **Деплой:** GitHub `lazy-ai-ui/lovely_radio` → Vercel. Каждый пуш в `main` уходит в прод. Ветки и PR получают превью-деплои с https-адресом: на них и проверяем iOS-поведение до мержа.
- Сборки нет, `vercel.json` не нужен. Vercel отдаёт статику с `max-age=0, must-revalidate`, так что после деплоя старый кэш не мешает.
