# refs/

Визуальные референсы для дизайна. В приложение не попадают и нигде в коде не подключаются.

## Раскладка

```
refs/
├─ noir/            референсы мира «нуар-джаз»
│  ├─ palette/      цвет: кадры из фильмов, плакаты, образцы
│  ├─ type/         шрифты и леттеринг: ар-деко, вывески, титры
│  ├─ texture/      жалюзи, зерно, бумага, тени
│  ├─ ui/           интерфейсы плееров и радио, которые нравятся
│  └─ motion/       видео и гифки с движением
└─ <следующий-мир>/
```

## Как называть файлы

`<что>-<откуда>.<ext>`, латиницей, через дефис. Например: `blinds-shadow-double-indemnity.jpg`, `lettering-chrysler-lobby.png`.

## Заметки

Рядом с папкой кладите `NOTES.md` по свободной форме: что именно нравится в каждом референсе (цвет, ритм, контраст, фактура). Claude читает его, когда переводит референсы в значения токенов в `tokens/theme-*.css`.

Тяжёлые видео лучше хранить ссылками в `NOTES.md`, а не файлами: репозиторий деплоится на Vercel целиком.
